# 洛克王国：世界 · 生蛋查询

这是一个离线 Windows 桌面工具。它保存多个账号各自的种公种母资料，按图鉴蛋组查找一至三代的生蛋路线。

## 运行

需要 Python 3.10 或更新版本，使用标准库，不需要安装依赖。

在项目目录运行：

```powershell
python app.py
```

个人记录和概率设置保存在 `data/personal.sqlite3`。该文件不进入 Git。备份时复制这个文件即可。

## 使用

1. 在顶部选择、重命名或新增账号；各账号精灵记录互相隔离。原有「账号 1/账号 2」数据会保留。
2. 在「种公种母」输入精灵全名或从筛选列表选精灵；编号、蛋组和进化家族自动关联图鉴。录入性别、成年精灵体重和可选身高、游戏可见的声音类别、异色与炫彩。无需输入奖牌或看不到的声音数值。
3. 在「概率参数与来源」填写自己确认的亲本单方遗传率。空白即未知；网页中互相矛盾的数值不会自动成为默认参数。
4. 在「生蛋路线」选目标精灵、最多代数和目标特征。没有来源的特征不会显示为可选目标，提示会提醒录入，已有记录始终保留。

查询要求公母共享至少一个蛋组，子代物种随母方家族的一阶精灵。选择进化形态作目标时，查询其一阶孵化形态；进化后的实际条件需自行核对。每个中间代可作为公或母继续繁育，但必须在实际孵化后取得相应性别。中间代只能与当前账号已录入的精灵再配对。路线较多时每层只保留最高 200 条候选、最终显示 50 条，因此结果不是穷举。

概率计算采用用户参数的简化模型：若每位有特征的亲本传递率为 `r`，双亲各自具有该特征的概率分别为 `p1`、`p2`，则子代估计为 `1-(1-p1*r)*(1-p2*r)`。不同目标特征的合并概率按独立近似相乘。它不是经过验证的游戏公式；每一项的具体概率及独立性均需继续核实。没有数值时显示「待确认」。结果另列性别路径概率，不与目标特征概率混淆。新生突变、孵化设备、活动加成和其他奖牌不纳入计算。

图鉴包含 625 条形态记录，578 条带已知蛋组。图鉴字段包括名称、编号、蛋组、性别比、身高、体重、精灵蛋重量及体型奖牌阈值。`data/pokedex.json` 是离线快照，来源与许可见 [SOURCES.md](SOURCES.md)。

联网刷新图鉴快照可运行 `python refresh_pokedex.py`。刷新后应重新核对数据来源和游戏版本。

## 限制

- WIKI 与玩家整理资料可能落后于游戏；请以游戏内当前版本核对。
- WIKI 的明确奖牌阈值属于精灵蛋重量，不能直接用于成年精灵。成年精灵的体型倾向按身高和体重在图鉴各自范围中的位置估算：两者都在最高 2% 为大块头倾向，都在最低 2% 为小不点倾向。这个 2% 是根据蛋重阈值作的启发式估计，并非已验证的成年精灵判牌公式；单录体重时不宣称已获得奖牌。
- 未发现蛋组不参与配对。其他特殊禁育规则可能未完整收录，结果仍需在游戏内确认。
- 旧版记录中的其他奖牌、手填体型标签及声音原始值仍在数据库中，不会因升级被删除；新界面不再录入或计算其他奖牌。
