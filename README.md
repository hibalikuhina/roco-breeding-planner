# 洛克王国：世界 · 生蛋查询

这是一个离线 Windows 桌面工具。它保存多个账号各自的种公种母资料，按图鉴蛋组查找一至三代的生蛋路线。

## 运行

需要 Python 3.10 或更新版本，使用标准库，不需要安装依赖。

在 Windows 资源管理器中双击 `launch-gui.lnk` 即可打开图形界面，不会留下命令行窗口。它直接调用 Python 的无控制台入口 `pyw.exe`。需要查看启动错误时，可以改用 `launch.cmd`；它会调用同目录的 `launch.ps1`，并在出错时保留窗口。Windows 通常不会把双击 `.ps1` 设为执行。

在项目目录运行：

```powershell
python app.py
```

账号、个人精灵记录和概率设置都保存在 `user_data/personal.sqlite3`。整个 `user_data` 文件夹不进入 Git。备份时复制 `user_data/personal.sqlite3` 即可。

## 使用

1. 全新数据默认只有一个账号，名称为「账号1」。可在顶部选择、重命名或新增账号；各账号精灵记录互相隔离。已有数据库中的账号及记录会保留。
2. 在「种公种母」选择精灵，录入性别、成年体重、声音奖牌类别、异色与炫彩。体重奖牌只需录入成年体重：工具按图鉴体重区间和可修改的「体型奖牌边缘」参数判定大块头、小不点或普通体型，无需另填奖牌。原始性格可直接输入名称，或分别选择加成属性和减益属性；选择单项会筛选其他选项，选定两项会自动补齐第三项。修改后的性格不会替代原始性格参与遗传。旧记录的性格为空，需自己补录。同种、同性别且繁育属性相同的记录在列表中合并计数；可在右侧切换同组的原始记录分别编辑，昵称和备注不影响分组。
3. 在「概率参数与来源」查看、修改并保存各项百分比。点「恢复全部默认值」可撤销自定义参数。1% 隐性炫彩、体型区间 ±2% 浮动及声音组合概率均明确标为尚未查明或模型假设。
4. 在「生蛋路线」填写目标精灵、指定母本、指定父本中的至少一项，再选最多代数和目标特征。六种目标特征始终可选。勾选「允许未录入亲本」后，查询可用图鉴中的兼容精灵补足父本或母本；结果用 `[未录入]` 标记需要自行取得的亲本。结果以列表显示最终父本、母本和子代；同种亲本的不同记录、子代公母及同编号形态合并为一行；若已录入同种同性别亲本，不再添加对应的未录入亲本。各记录的属性、概率和完整繁育步骤在双击详情中查看。完整性格、加成属性、减益属性任选一项会筛选可用组合，选两项会自动补齐第三项。无原始性格的旧记录仍保留，相关概率显示待确认。
5. 生蛋路线的选项按账号自动保存在 `user_data/personal.sqlite3`；「清空选项」清除当前账号的查询选项和界面结果，不删除精灵记录或概率参数。

查询要求公母共享至少一个蛋组，子代物种随母方家族的一阶精灵。选择进化形态作目标时，查询其一阶孵化形态；进化后的实际条件需自行核对。每个中间代可作为公或母继续繁育，但必须在实际孵化后取得相应性别。两条一代路线的子代再配对，需要三次繁育，计为三代。默认只使用当前账号已录入的亲本；允许未录入亲本时，图鉴精灵按成年体重区间中值、普通声音、无异色炫彩、原始性格未知建模。这些是假设，不代表玩家实际拥有或能立即取得。只要一方亲本按体重和当前边缘参数判为大块头或小不点，就可保留模型估算为 0% 的对应目标路线；这不是获牌概率的保证。规划中的子代若要作为带牌亲本，须先孵出符合对应体重奖牌判定的个体。候选挑选优先考虑非零概率、较少繁育次数和较少未录入亲本；列表按父本编号、母本编号、子代编号排序，同编号形态及子代性别合并为一行，详细形态和概率在双击详情中查看。路线较多时每层只保留最高 200 条中间候选，最终列表最多显示 200 条，并为保留的 0% 路线预留少量位置，因此结果不是穷举。

显性外观采用双亲独立机会近似：`P(显性)=1-(1-p父·r)(1-p母·r)`；普通蛋近似为两种显性外观都未出现，隐性概率只加在普通蛋的部分，结果同时列出两部分。性格按「整套 +/−」以默认父 30%、母 30%、随机 40% 混合，再分别统计目标性格名、加成和减益。随机部分暂按 30 种性格均匀分配。声音仅用婉转声、粗嗓门和无牌三个类别的可编辑转移概率。体重奖牌把双亲各自的成年体重换算为其图鉴区间位置，取均值并按可编辑的区间幅度浮动；多代概率用矩近似。不同特征的联合概率按独立近似相乘；结果另列性别路径概率。这些模型不等于游戏实际判定代码。

图鉴包含 625 条形态记录，578 条带已知蛋组。每条都保存成年精灵体重范围和身高范围，另有名称、编号、蛋组、性别比等字段；本地数据不保存蛋重范围。赛季字段按新版 WIKI 的「归属赛季」记录，包含当季新增异色和特殊形态，不能只按新精灵名单判断。`data/pokedex.json` 是离线快照，来源与许可见 [SOURCES.md](SOURCES.md)。

联网刷新图鉴快照可运行 `python refresh_pokedex.py`。脚本从结构化镜像读取基础资料，并按精灵 ID 从新版 WIKI 精灵列表补充赛季；两边记录无法对应时会报错，不覆盖现有快照。刷新后应重新核对数据来源和游戏版本。

勾选「异色」目标时，仅显示图鉴 `has_shiny` 标为支持异色的子代；不支持异色的子代按 0% 计算。

## 限制

- WIKI 与玩家整理资料可能落后于游戏；请以游戏内当前版本核对。
- 体重奖牌按录入体重在图鉴范围中的位置判定：默认最高 2% 为大块头，最低 2% 为小不点。玩家蛋重阈值支持两端各 2%；工具将这一比例用于成年体重，属于可修改的模型参数，需以游戏内结果核对。
- 声音数值在游戏内不可直接查看，声音传承的奖牌模型没有实测概率；请按游戏内可见奖牌或「普通」录入。
- 未发现蛋组不参与配对。其他特殊禁育规则可能未完整收录，结果仍需在游戏内确认。
- 旧版记录中的其他奖牌、手填体型标签及声音原始值仍在数据库中，不会因升级被删除；新界面不再录入或计算其他奖牌。
