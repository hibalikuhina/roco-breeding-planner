# 洛克王国：世界 · 生蛋查询

这是一个离线 Windows 桌面工具。它保存多个账号各自的种公种母资料，按图鉴蛋组查找一至三代的生蛋路线。

## 运行

需要 Python 3.10 或更新版本，使用标准库，不需要安装依赖。

在 Windows 资源管理器中双击 `launch-gui.lnk` 即可打开图形界面，不会留下命令行窗口。它直接调用 Python 的无控制台入口 `pyw.exe`。需要查看启动错误时，可以改用 `launch.cmd`；它会调用同目录的 `launch.ps1`，并在出错时保留窗口。Windows 通常不会把双击 `.ps1` 设为执行。

在项目目录运行：

```powershell
python app.py
```

个人记录和概率设置保存在 `data/personal.sqlite3`。该文件不进入 Git。备份时复制这个文件即可。

## 使用

1. 在顶部选择、重命名或新增账号；各账号精灵记录互相隔离。原有「账号 1/账号 2」数据会保留。
2. 在「种公种母」选择精灵，录入性别、成年体重、可选身高、声音奖牌类别、异色与炫彩。原始性格可直接输入名称，或分别选择加成属性和减益属性；工具会自动换算。修改后的性格不会替代原始性格参与遗传。旧记录的性格为空，需自己补录；无需输入编号或体型奖牌。
3. 在「概率参数与来源」查看、修改并保存各项百分比。点「恢复全部默认值」可撤销自定义参数。1% 隐性炫彩、体型区间 ±2% 浮动及声音组合概率均明确标为尚未查明或模型假设。
4. 在「生蛋路线」选目标精灵、最多代数和目标特征；完整性格、只看加成属性、只看减益属性可分别查询。无原始性格的旧记录仍保留，相关概率显示待确认。

查询要求公母共享至少一个蛋组，子代物种随母方家族的一阶精灵。选择进化形态作目标时，查询其一阶孵化形态；进化后的实际条件需自行核对。每个中间代可作为公或母继续繁育，但必须在实际孵化后取得相应性别。中间代只能与当前账号已录入的精灵再配对。路线较多时每层只保留最高 200 条候选、最终显示 50 条，因此结果不是穷举。

显性外观采用双亲独立机会近似：`P(显性)=1-(1-p父·r)(1-p母·r)`；普通蛋近似为两种显性外观都未出现，隐性概率只加在普通蛋的部分，结果同时列出两部分。性格按「整套 +/−」以默认父 30%、母 30%、随机 40% 混合，再分别统计目标性格名、加成和减益。随机部分暂按 30 种性格均匀分配。声音仅用婉转声、粗嗓门和无牌三个类别的可编辑转移概率。体型把双亲各自的成年体重和身高换算为其图鉴区间位置，取均值并按可编辑的区间幅度浮动；多代体型概率用矩近似。不同特征的联合概率按独立近似相乘；结果另列性别路径概率。这些模型不等于游戏实际判定代码。

图鉴包含 625 条形态记录，578 条带已知蛋组。每条都保存成年精灵体重范围和身高范围，另有名称、编号、蛋组、性别比等字段；本地数据不保存蛋重范围。`data/pokedex.json` 是离线快照，来源与许可见 [SOURCES.md](SOURCES.md)。

联网刷新图鉴快照可运行 `python refresh_pokedex.py`。刷新后应重新核对数据来源和游戏版本。

## 限制

- WIKI 与玩家整理资料可能落后于游戏；请以游戏内当前版本核对。
- 成年精灵的体型倾向按身高和体重在图鉴各自范围中的位置估算：两者都在最高 2% 为大块头倾向，都在最低 2% 为小不点倾向。玩家蛋重阈值支持两端各 2%，成年精灵判牌仍是估算。只录体重时会保留记录，但体型概率显示待确认。
- 声音数值在游戏内不可直接查看，声音传承的奖牌模型没有实测概率；请按游戏内可见奖牌或「普通」录入。
- 未发现蛋组不参与配对。其他特殊禁育规则可能未完整收录，结果仍需在游戏内确认。
- 旧版记录中的其他奖牌、手填体型标签及声音原始值仍在数据库中，不会因升级被删除；新界面不再录入或计算其他奖牌。
